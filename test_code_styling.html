Code Block Styling Test for ePub Export

This page demonstrates the new code block styling for LinkedIn Articles ePub exports.

Requirements

Before: Code blocks had light gray background (#f5f5f5) with default text color
After: Code blocks have dark blue background (#1a3a52) with white bold text
Purpose: Better readability and suitability for printing

Test Case 1: Multi-line Code Block

This is a typical code block that might appear in a LinkedIn article:

def calculate_fibonacci(n):
    if n <= 1:
        return n
    return calculate_fibonacci(n-1) + calculate_fibonacci(n-2)

# Example usage
for i in range(10):
    print(f"F({i}) = {calculate_fibonacci(i)}")

Test Case 2: Long Line Code Block (Testing Word Wrap)

Code blocks should wrap long lines properly, not overflow:

const veryLongFunctionName = (param1, param2, param3, param4, param5, param6, param7, param8) => {
    return param1 + param2 + param3 + param4 + param5 + param6 + param7 + param8;
};

// This is a very long comment that should also wrap properly when displayed in the ePub reader and not cause any horizontal scrolling issues

Test Case 3: Inline Code

You can also use inline code like console.log("Hello World") within regular paragraphs. The styling should be consistent but not disrupt the text flow.

Test Case 4: SQL Query

SELECT 
    users.id,
    users.name,
    COUNT(articles.id) as article_count
FROM users
LEFT JOIN articles ON users.id = articles.author_id
WHERE users.active = true
GROUP BY users.id, users.name
HAVING article_count > 5
ORDER BY article_count DESC
LIMIT 10;

Test Case 6: Mixed Content

Here's a paragraph explaining that you should use the fetch_article_rich() method to download article content. This method returns a dictionary with keys like html, images, and banner_image.

result = sess.fetch_article_rich(article_url)
print(f"HTML length: {len(result['html'])}")
print(f"Image count: {len(result['images'])}")
if result['banner_image']:
    print("Banner image found!")

Visual Check

✓ Checklist:

  • Code blocks have dark blue background (#1a3a52)
  • Text is white and bold
  • Long lines wrap properly (no horizontal scroll)
  • Inline code matches block code styling
  • Text is readable when printed or viewed on e-readers

Notes

This styling will be embedded in the ePub CSS and applied to all <pre> and <code> elements in exported ePub files. The original LinkedIn article content is converted to use standard HTML <pre> tags during the scraping process.
